# Machine Learning / CNN and Visual Representation: AlexNet, the Starting Point of Deep Visual Learning

Paper: [ImageNet Classification with Deep Convolutional Neural Networks](https://proceedings.neurips.cc/paper_files/paper/2012/file/c399862d3b9d6b76c8436e924a68c45b-Paper.pdf)

Code repository: `paper-reforge/AlexNet`

## Before Starting

The first thing to keep straight is that AlexNet is still a CNN. It is not something outside CNNs. It is the point where CNNs moved from "working on clean small datasets" to "beating traditional vision methods on large-scale real-world image classification."

If LeNet-5 showed that CNNs could recognize images, AlexNet showed that CNNs could become the main approach on a difficult dataset like ImageNet.

This note mostly follows the order of the paper, with one comparison in mind:

```text
LeNet / small-scale CNNs
vs
AlexNet / large-scale ImageNet CNNs
```

The questions I want to keep asking are:

```text
What did AlexNet add beyond earlier CNNs?
Why did it become the starting point of deep visual learning?
```

At its core:

```text
AlexNet encodes an image into convolutional features, then maps those features to a probability distribution over 1000 fixed ImageNet classes.
```

So it is a closed-set classification task:

```text
Given an image, score each of the 1000 predefined ImageNet categories.
```

## Abstract / Introduction: The Problem Got Bigger

The title of the paper is *ImageNet Classification with Deep Convolutional Neural Networks*. The important words are already there:

```text
ImageNet
Deep CNN
Classification
```

This is a very different problem from MNIST, which LeNet-5 was built around.

MNIST is a clean introductory task:

```text
grayscale images
handwritten digits
10 classes
simple backgrounds
objects mostly centered
```

ImageNet is natural image classification:

```text
color images
complex backgrounds
1000 classes
large changes in scale and pose
about 1.2 million training images
```

That means a small CNN is no longer enough. AlexNet needed a larger model, more compute, stronger regularization, and faster training choices.

The most important result in the paper is simply that AlexNet was much better than the previous approaches:

```text
ILSVRC-2010:
top-1 error = 37.5%
top-5 error = 17.0%

ILSVRC-2012:
AlexNet top-5 error = 15.3%
runner-up top-5 error = 26.2%
```

The exact metric details are not the main point here. The important thing is that this was not a small lead. It was large enough to change the direction of computer vision.

AlexNet made this combination convincing:

```text
large data + large CNN + GPU + ReLU + dropout / data augmentation
```

Together, these were enough to beat hand-engineered vision pipelines on a real visual recognition benchmark.

## Dataset: From MNIST to ImageNet

LeNet-5 handled handwritten digit recognition. AlexNet handled ImageNet classification with 1000 natural image classes. That change affects the whole network design.

On MNIST, images are regular and the number of classes is small. The model mostly learns digit shapes.

On ImageNet, the same category can appear in many different situations:

```text
different viewpoints
different lighting
different backgrounds
different scales
different occlusions
```

So AlexNet has to learn much richer visual representations.

This is also why AlexNet does not output digit classes. It outputs:

```text
1000 ImageNet-class logits
```

The final layer produces a vector of length 1000:

```text
[
  class_0_score,
  class_1_score,
  ...,
  class_999_score
]
```

Those scores are then passed through softmax to become a probability distribution over the 1000 classes.

The "1000 options" are not generated by the model on the fly. They come from ImageNet's predefined label space. In other words, AlexNet is doing closed-set classification:

```text
The answer must be chosen from these 1000 classes.
```

This also explains what happened when I ran pretrained AlexNet on a game character image. It returned labels like `gasmask`, `wig`, or `stage`, not because it understood the character, but because ImageNet does not contain that character as an option. The model can only choose the closest labels from the classes it knows.

## Architecture: The AlexNet Structure

The main structure of AlexNet is:

```text
5 convolutional layers
+ 3 fully connected layers
```

Expanded:

```text
Input
-> Conv1 -> ReLU -> LRN -> Pool
-> Conv2 -> ReLU -> LRN -> Pool
-> Conv3 -> ReLU
-> Conv4 -> ReLU
-> Conv5 -> ReLU -> Pool
-> Flatten
-> FC6 -> ReLU -> Dropout
-> FC7 -> ReLU -> Dropout
-> FC8
-> Softmax
```

This is still the standard CNN idea:

```text
convolutional layers extract visual features
fully connected layers combine those features for classification
```

Compared with LeNet, AlexNet is deeper, wider, built for more complex inputs, and aimed at a much larger label space.

### 3.1 ReLU: Making Large CNN Training Practical

Earlier neural networks often used `sigmoid` or `tanh`. Their problem is saturation:

```text
when the input is very large or very small, the gradient becomes close to 0
```

In a deep network, if gradients keep shrinking, earlier layers become hard to train.

AlexNet uses ReLU:

```text
f(x) = max(0, x)
```

ReLU does not saturate on the positive side, so training becomes much faster. The paper mentions a CIFAR-10 experiment where a ReLU network reached the same training error about six times faster than a tanh network. For a large CNN like AlexNet, ReLU was one of the key conditions that made training practical.

### 3.2 Multiple GPUs: Hardware Shaped the Model

AlexNet was trained on two GTX 580 GPUs. Each GPU had only 3GB of memory, so the full model could not be handled as easily as it would be today.

The paper used a model-parallel setup:

```text
some kernels / channels on GPU 1
some kernels / channels on GPU 2
some layers communicate across GPUs
some layers only connect to feature maps on the same GPU
```

This is different from the data parallelism that is common today.

Data parallelism is more like:

```text
different GPUs process different parts of the batch
then synchronize gradients
```

AlexNet was closer to:

```text
the model itself is split across two GPUs
```

The paper says the two-GPU network worked better than a single-GPU network with about half as many kernels. I do not read that as "multiple GPUs magically improve accuracy." The more natural reading is:

```text
two GPUs allowed the authors to train a larger network
a larger network had more capacity
so it worked better
```

This is one reason AlexNet feels less like a single algorithmic trick and more like a moment when several conditions finally lined up: data, model size, GPU compute, and training choices.

### 3.3 LRN: An Early Channel-Competition Normalization

LRN means Local Response Normalization.

The intuition is:

```text
at the same spatial position, nearby channels compete with each other
strong responses stand out, and neighboring responses are suppressed a little
```

AlexNet used LRN after ReLU in Conv1 and Conv2:

```text
Conv1 -> ReLU -> LRN -> Pool
Conv2 -> ReLU -> LRN -> Pool
```

The idea was inspired by lateral inhibition in biological vision.

Today, LRN is rarely used. BatchNorm, LayerNorm, and related normalization methods became more stable and more general.

### 3.4 Overlapping Pooling: A Smoother Downsampling Step

A common pooling setup is:

```text
2x2 pooling, stride 2
```

The windows do not overlap.

AlexNet used:

```text
3x3 max pooling, stride 2
```

Since the window size is larger than the stride, neighboring pooling regions overlap. This helps reduce the information loss caused by hard, non-overlapping blocks.

### 3.5 Overall Architecture: Shape Chain

The classic AlexNet shape calculation usually uses a `227x227x3` input, because that works cleanly with the Conv1 parameters in the paper.

The spatial sizes are roughly:

```text
227
-> Conv11/s4: 55
-> Pool3/s2: 27
-> Conv5/p2: 27
-> Pool3/s2: 13
-> Conv3/p1: 13
-> Conv3/p1: 13
-> Conv3/p1: 13
-> Pool3/s2: 6
```

The full shape chain:

```text
1x3x227x227
-> 1x96x55x55
-> 1x96x27x27
-> 1x256x27x27
-> 1x256x13x13
-> 1x384x13x13
-> 1x384x13x13
-> 1x256x13x13
-> 1x256x6x6
-> 1x9216
-> 1x4096
-> 1x4096
-> 1x1000
```

One easy trap is to confuse output activations with parameters.

For Conv1, the output is:

```text
96 x 55 x 55
```

That is the number of activation values produced by the layer.

But the number of Conv1 parameters is:

```text
96 x 11 x 11 x 3 + 96 = 34,944
```

The reason is weight sharing. The same convolution kernel slides across the whole image. One kernel produces a `55x55` feature map, but all positions in that map share the same set of weights.

The fully connected layers are different. FC6 maps:

```text
9216 -> 4096
```

Its parameter count is:

```text
9216 x 4096 + 4096 = 37,752,832
```

So most of AlexNet's parameters are actually in the fully connected layers, not in the convolutional layers.

## Reducing Overfitting: The Cost of a Large Model

AlexNet has about 60 million parameters. ImageNet is large, but overfitting is still a real issue for a model of this size.

The paper mainly used two methods:

```text
data augmentation
dropout
```

### Data Augmentation

During training, the authors randomly cropped `224x224` patches from `256x256` images and used horizontal flips.

This tells the model:

```text
if the object moves a little, the class does not change
if the object is flipped horizontally, the class usually does not change
```

At test time, they used 10-crop evaluation:

```text
four corners + center = 5 crops
original image + horizontally flipped image = 10 crops
```

The predictions were averaged.

They also used PCA color perturbation to make the model more robust to lighting and color changes.

So the main idea of data augmentation is:

```text
expand the training distribution using transformations that preserve the label
```

### Dropout

Dropout was used in FC6 and FC7.

During training, dropout randomly sets part of the hidden activations to zero. The paper used probability 0.5.

The intuition:

```text
each training step temporarily turns off some neurons
the model cannot rely on fixed neuron groups to memorize the training set
```

This mattered a lot for AlexNet because FC6 and FC7 were huge:

```text
FC6: 37.7M
FC7: 16.8M
```

Without dropout, these fully connected layers could easily memorize training-set details.

## Details of Learning: The Training Recipe

AlexNet used SGD with momentum.

The main training settings were:

```text
batch size = 128
momentum = 0.9
weight decay = 0.0005
initial learning rate = 0.01
```

The learning rate was reduced manually: when validation error stopped improving, it was divided by 10.

The training time also says a lot about the era:

```text
two GTX 580 3GB GPUs
about 5-6 days of training
90 epochs
```

That may not sound extreme today, but in 2012 it shows how much AlexNet depended on engineering and hardware.

## Results / Discussion: Why It Became a Turning Point

The most famous AlexNet result is from ILSVRC-2012:

```text
AlexNet top-5 test error = 15.3%
runner-up top-5 test error = 26.2%
```

The gap was huge, and it almost directly changed the direction of computer vision.

The discussion section also includes an important observation: removing any convolutional layer made performance worse.

That suggests AlexNet's success was not just about having many parameters. Depth itself mattered. Multiple convolutional layers can gradually compose features:

```text
edges / colors
-> textures / local shapes
-> object parts
-> class-related representations
```

AlexNet opened the path for later models:

```text
VGG
GoogLeNet
ResNet
ViT
CLIP
```

Later models continued in the direction of deeper, cleaner, more trainable, and more expressive visual representations.

## Lightweight Reproduction

Training the full ImageNet AlexNet from scratch is expensive, so I treated this as a lightweight reproduction:

```text
1. paper-style AlexNet structure
2. dummy-input shape inspection
3. parameter counting
4. real-image inference with torchvision's pretrained AlexNet
```

The code is in:

```text
paper-reforge/AlexNet
```

The important files are:

```text
src/models.py              hand-written AlexNetPaper
src/inspect_shapes.py      layer shape inspection
src/predict_pretrained.py  pretrained AlexNet inference with torchvision
outputs/layer_shapes.csv   shape table
```

The main value of this reproduction is:

```text
being able to explain how AlexNet goes from an image to 1000-class logits
distinguishing model structure, weights, logits, and softmax probabilities
explaining why AlexNet is closed-set classification, not open-ended image understanding
```

## Summary

AlexNet can be compressed into this chain:

```text
image
-> CNN feature extractor
-> flatten
-> fully connected classifier
-> 1000-class logits
-> softmax probabilities
```

Compared with earlier CNNs, its key advances were:

```text
larger data: ImageNet
larger model: about 60 million parameters
faster activation: ReLU
stronger engineering: GPU parallelism
more serious regularization: data augmentation + dropout
```

As a milestone, AlexNet was not the end of CNNs. It was the point where modern deep visual learning really took off.
