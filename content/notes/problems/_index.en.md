# Problem Set

Companion exercises grouped into per-subject subpages, each problem listed one per entry with a collapsible reference solution.

{{< problem-map kind="home" >}}

> Many problems carry a "prove it again in another language" flavor — re-deriving the same result with a different tool (convexity, geometry, variation…). The point is not the answer but seeing that it is the same thing as something elsewhere.

## Branches

- [**Real Analysis**](/en/notes/problems/real-analysis/) — sequences, completeness, measure, $L^p$… single-tool to start, each solution led by a one-line "skeleton" (which verb to reach for).
- [**Optimization and Calculus of Variations**](/en/notes/problems/optimization-variation/) — Lagrange multipliers, maximum entropy, convex duality; mostly "one thing in two languages."
- [**Miscellaneous**](/en/notes/problems/misc/) — the pigeonhole principle and other combinatorics / discrete puzzles.
