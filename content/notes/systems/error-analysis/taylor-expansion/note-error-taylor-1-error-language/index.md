在讨论“Taylor 展开准不准”之前，我们要先回答一个更基础的问题：

> 我们口中的误差，究竟是哪一个数学对象？

设

\[
P_n(x)=\sum_{k=0}^{n}\frac{f^{(k)}(a)}{k!}(x-a)^k.
\]

Taylor 余项定义为

\[
\boxed{R_n(x)=f(x)-P_n(x).}
\]

这是一个带符号的精确差值。目前只说明了“真值减去近似值剩下什么”。

## 1. 四个概念

### 1.1 Actual error

给定 \(f,a,n,x\) 后，\(R_n(x)\) 就是这个具体问题的真实误差。若只关心距离，则使用

\[
|R_n(x)|.
\]

所以 \(R_n\) 不是“绝对误差函数”；它保留高估或低估的符号，\(|R_n|\) 才是绝对误差。

### 1.2 Representation

Lagrange、integral 和 Peano remainder 都在描述余项，但它们是不同的信息表示，不是余项本身的定义。表示式可能包含未知中间点、积分或渐近记号。

### 1.3 Asymptotic order

写

\[
R(h)=O(h^p)
\]

表示在目标极限附近存在常数 \(C\)，使得

\[
|R(h)|\le C|h|^p.
\]

它说明相对于 \(h^p\)，比值不会无限增长。

而

\[
R(h)=o(h^p)
\]

表示

\[
\frac{R(h)}{h^p}\to0.
\]

这不是另一个方向的界，而是更强的“相对可忽略”关系。

### 1.4 Numerical bound

如果希望实际认证某次计算，需要的不只是 \(O(h^p)\)，而是明确的常数和有效范围，例如

\[
|R(h)|\le \frac{|h|^3}{6},
\qquad |h|\le0.1.
\]

渐近阶告诉我们缩放规律；数值界才告诉我们这一次最多可能差多少。

## 2. \(O\) 与 \(o\) 的直觉理解

最容易出现的误解是：

\[
O=\text{上限},\qquad o=\text{下限}.
\]

实际上二者都不是在一条数轴上夹住误差。它们比较的是两个函数在极限附近的相对尺度：

- \(O(g)\)：\(R/g\) 有界；
- \(o(g)\)：\(R/g\to0\)。

因此同一个误差可以同时属于很多个 \(O\) 类。

以

\[
R_2(x)=\sin x-x
\]

为例，

\[
R_2(x)=-\frac{x^3}{6}+o(x^3).
\]

于是它同时满足

\[
R_2=O(x^3),\qquad R_2=O(x^2),\qquad R_2=o(x^2),
\]

但不满足 \(R_2=o(x^3)\)，因为

\[
\frac{R_2(x)}{x^3}\to-\frac16\ne0.
\]

\(O(x^2)\) 虽然正确，却没有抓住真实的三阶衰减。这已经预告了后面的核心问题：**正确的信息也可能太松。**

直觉上，
- 大 $O$ 关注“从哪一阶开始”：写成 $O(x^3)$，就是在明确告诉大家：“后面的误差是从 $x^3$ 这一阶（及更高阶）开始的，它的量级最大也就是 $x^3$ 的常数倍。”它给出了误差从哪一阶截断/封顶的确定信息。

- 小 $o$ 关注“以目前展开阶为基”：写成 $o(x^2)$，意思是：“以目前展开到的 $x^2$ 为基准，后面的误差比 $x^2$ 还要小得多（是更高阶的无穷小）。”它只是借用目前展开的最后一项（比如 $x^2$），来保证误差比它降得更快，但并不承诺误差具体是从 $x^3$、$x^4$ 还是 $x^{2.5}$ 开始。

## 3. 主导项把“量级”变成可解释结构

若

\[
R(h)=Ch^p+o(h^p),
\qquad C\ne0,
\]

则 \(Ch^p\) 是主导项。它比单独写 \(O(h^p)\) 多保留了：

- 符号；
- 首项系数；
- 精确的首个非零阶；
- 尺度改变时的误差倍率。

例如将 \(h\) 减半：

\[
\frac{R(h/2)}{R(h)}\to2^{-p}.
\]

这条缩放规律是之后 observed order 和 Richardson extrapolation 的依据。

## 4. 检查

看到一个误差公式时，至少检查：

1. reference 是什么；
2. approximation 是什么；
3. 误差是否保留符号；
4. 结论是精确等式、渐近式还是不等式；
5. 极限变量是谁；
6. 常数与有效区间是否已知；
7. 该结论能否直接用于一次具体计算。

把这些语言固定下来后，下一步才是比较不同余项公式究竟保留了多少误差信息。
